配置流程（重点）

请按顺序完成，不要跳过「更新订阅」。任何第三方修改过的配置文件都不视为 DLK 官方来源。

  1. 确认套餐与设备数

    对照同时在线设备选择基础版、旗舰版或团队版。电脑、手机、平板各计一台。年付仅改变结算周期，不改变流量包规格。

  2. 在官网账户获取订阅链接

    登录后复制 Clash / Surge / 通用订阅地址。链接含访问令牌，不要发到公开群组。若链接泄露，在账户内重置后再导入。

  3. 下载对应系统的官方客户端

    前往本页客户端下载区，仅使用标注系统版本的安装包。Windows 与 macOS 选稳定内核，Android 可用 Clash Meta 系，iOS 使用商店内已有客户端并手动填订阅。

  4. 导入订阅并开启规则模式

    粘贴订阅 URL，允许自动更新。规则模式选「规则」而非全局，可减少国内站点绕行。DNS 使用客户端内置或加密 DNS，避免污染导致假超时。

  5. 测速、锁定节点、保存配置

    先测延迟再测下载。流媒体选标注解锁的区域节点，游戏选 IPLC。将常用节点加星，下次打开客户端即可一键连接。

导入后检查清单

系统代理端口是否被占用；是否允许局域网连接；流量统计是否开始跳动；订阅剩余天数是否与套餐一致。若仅浏览器能通、其他软件不通，打开「系统代理」或为该软件单独设置端口。

配置失败时

先删除旧配置再重新导入，避免残留规则。旗舰版与团队版走优先工单，说明系统版本、客户端名称与报错原文即可。

常见问题

DLK 和普通 VPN 加速器有什么区别？

DLK 以机场订阅为核心：一份订阅可在多个客户端使用，节点与规则由服务端更新。传统单机 VPN 往往只有固定出口，缺少按应用分流。若你需要流媒体解锁和游戏专线，应选带 IPLC 与原生解锁说明的套餐。

如何完成官网下载并导入客户端？

先登录获取订阅 URL，再按系统下载对应客户端。打开客户端选择「从 URL 导入」，粘贴链接并允许自动更新。导入成功后切到规则模式，选延迟较低的节点连接。详细顺序见「配置流程」五步。

流量、设备数和年付如何计算？

流量按自然月重置，不结转。同时在线设备数按套餐上限统计，同一账号多终端登录会占用名额。年付价格为基础月价的十倍，周期内规格不变。超额将降速或需要升级，不会在未提示时扣费。

看视频或玩游戏应该选哪类节点？

视频选标注解锁的区域节点，优先旗舰版全节点原生解锁。游戏走 IPLC，关闭不必要的广告过滤规则以免误伤对战平台。若只有基础版，先用普通线路测速，延迟不稳定时再考虑升级。

连接成功但部分网站打不开怎么办？

通常是 DNS 或规则问题。改用客户端内加密 DNS，确认不是全局拦截国内站点。公司网络若拦截代理端口，可尝试备用端口配置。仍失败时提供追踪 ID 给工单，避免只说「连不上」。

团队版怎样做企业定制路由？

开通后由专属客户经理收集需要直连与需要加速的域名列表，在后台下发分流。员工各自导入同一订阅即可，不必每人单独改规则。设备上限为 20 台同时在线，超出需扩容。
